# Judgement Call Demo Guide

This guide explains how to run the Judgement Call local demo scripts, replay stored timelines, execute the test suite, and understand the human-in-the-loop decision flow.

## Overview

Judgement Call is an autonomous agent framework protected by the **Attention Governor** and cedar authorization policies. In the `concurrency-demo` scenario, the worker agent is tasked with refactoring synchronous queue processing in `src/demoqueue/processor.py` into concurrent execution using `concurrent.futures`, while preserving the public signature (`process_items(items, worker)`) and input result order.

---

## 1. Running the Local Demo (`scripts/demo_local.py`)

The local demo script supports both offline simulation mode (default) and live Bedrock mode.

### Offline Mode (Default)
Runs the end-to-end workflow locally without requiring AWS credentials:
```bash
python scripts/demo_local.py --offline
```
**What happens in offline mode:**
1. Initializes workspace from `fixtures/concurrency_demo`.
2. Worker inspects workspace and proposes an internal/reversible decision (pool type selection) which is **auto-resolved** by the Attention Governor (`auto_resolved >= 1`).
3. Modifies `src/demoqueue/processor.py` to execute concurrently using `concurrent.futures` while preserving signature and input order.
4. Encounters a material architectural choice (exception handling strategy) producing a **Decision Card** (`human_interrupts == 1`).
5. Resumes execution with choice `'A'`.
6. Executes the **IndependentVerifier** running acceptance tests.
7. Prints completed status, code diff, and the real Attention Receipt (`final_verifier_passed=True`).

### Live Mode
Invokes Amazon Bedrock when AWS credentials are configured:
```bash
python scripts/demo_local.py --live --session-id session-live-1
```

## 2. Replaying Stored Timelines (`scripts/replay_demo.py`)

To inspect a recorded run or demonstrate the flow without executing live AI or offline simulation:
```bash
python scripts/replay_demo.py
```
This displays a prominent `[REPLAY MODE]` banner and replays stored timeline events step-by-step (tool calls, auto-resolutions, Decision Card presentation, resume, and final Attention Receipt).

---

## 3. Human-in-the-Loop Decision Flow

During complex runs, the Attention Governor intercepts high-impact or irreversible proposals and surfaces a **Decision Card** requesting human intervention:
- **Decision Proposals:** Generated by the agent when trade-offs arise.
- **Attention Governor Gate:** Evaluates proposals deterministically or via Gate Agent. Reversible/low-impact items are **auto-resolved**; material architectural trade-offs trigger **human interrupts** (`ASK_HUMAN`).
- **Resume:** The human inspects the Decision Card (question, options, recommendation, evidence) and responds with a `choice_id` (e.g. `'A'`) and optional note.
- **Attention Receipt:** Records final metrics including proposal counts, auto-resolutions, human interrupts, tool calls, test runs, and verifier pass status.

---

## 4. Running Tests

Run the complete test suite including unit tests and live/offline demo flow tests:
```bash
PYTHONPATH=. pytest
```
To run specific demo flow tests:
```bash
PYTHONPATH=. pytest tests/live/test_demo_flow.py
```
*(Live tests marked with `@pytest.mark.live` are automatically skipped if AWS credentials are absent).*
